# 99HOMES Premium Redesign Concept

A responsive Next.js concept website for 99homes Realty Inc. Brokerage.

## Run locally

Requirements: Node.js 20+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Before presenting or launching

This is a redesign concept, not an approved or production-integrated brokerage website.

- Confirm all company details, team names, phone numbers, address and regulatory disclosures with 99homes.
- Verify project availability, prices, incentives, floor plans, developers and completion dates directly with the brokerage/developer before publishing.
- Replace illustrative Unsplash photography with licensed project photography.
- The inquiry form currently opens a pre-filled WhatsApp message to the brokerage's publicly advertised contact number; it does not store leads in a database.
- Confirm brokerage approval for branding, content, images, lead routing and any claims.
- The current project cards are an initial illustrative selection based on public website information and must be reviewed before launch.

## Design notes

- Editorial luxury visual direction: warm ivory, charcoal, muted olive and champagne.
- Responsive navigation and layout.
- Project search filters by project/city/developer and property type.
- Inquiry flow launches WhatsApp with the visitor's details.
- No external CRM, MLS feed, database or admin dashboard is connected yet.
